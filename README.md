# InnovArch – Smart Architect's Office Desktop Application

InnovArch is a smart and intuitive desktop application designed to modernize and simplify the day-to-day management tasks within an architect’s office. Built using **C++** and **Qt Creator 6.7.3**, it centralizes core functions such as contractor relations, project monitoring, client tracking, and more into a unified, ergonomic platform.

---

## 🚀 Features by Module

This app is developed collaboratively, with each team member responsible for a specific module:

- 🔧 **Gestion Contracteurs** — *by Dhia Bondka*  
  Manage contractor records, specializations, and performance tracking with a built in to-do list.

- 🧾 **Gestion Contrats** — *by Youssef Ben Said*  
  Handle contract generation, status tracking, deadlines, and payments.

- 🏗️ **Gestion Projets** — *by Ahmed Belkhiria*  
  Follow project lifecycles from budgeting to delivery with real-time updates and detailed reports.

- 👤 **Gestion Clients** — *by Selim Ben Abdelkader*  
  Store and retrieve detailed client data, project history, and customer feedback.

- 🧑‍🎨 **Gestion Architectes** — *by Ons Nagara*  
  Organize architect profiles, assign projects, track work hours, and analyze productivity.

- 📦 **Gestion Ressources** — *by Maram El Manaa*  
  Maintain hardware inventory, monitor equipment status, and plan procurement cycles.

---

## 🎯 Why InnovArch?

Unlike existing tools like *Houzz Pro* or *ArchDesk*, InnovArch provides a cost-efficient, all-in-one solution tailored to the **specific needs of architectural agencies** with:

- Centralized resource and project management
- Real-time dashboards and notifications
- PDF/Excel report generation
- Modern, user-friendly UI with a refined color palette
- Scalable modular design
